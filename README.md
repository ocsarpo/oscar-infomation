## 한양도성 지도 트랙

`route-data.js`의 1코스는 서울시 스마트서울맵 **한양도성 순성길_백악구간(B_040)** 공식 선형을 정적 좌표로 변환한 것입니다. 2~4코스는 2025-10-08에 기록된 한양도성 1바퀴 GPX 트랙을 사용합니다. 원본 GPX는 저장소에 포함하지 않으며, GPS 기록 구간은 창의문·혜화문·광희문·숭례문에 가장 가까운 트랙 포인트를 경계로 잡아 **창의문 → 혜화문 → 광희문 → 숭례문 → 창의문** 순서가 되도록 역순으로 저장했습니다.
