## 한양도성 지도 트랙

`route-data.js`는 2025-10-08에 기록된 한양도성 1바퀴 GPX 트랙을 정적 좌표로 변환한 파일입니다. 원본 GPX는 저장소에 포함하지 않으며, 창의문·혜화문·광희문·숭례문에 가장 가까운 트랙 포인트를 경계로 잡아 **창의문 → 혜화문 → 광희문 → 숭례문 → 창의문** 순서의 4개 구간으로 분할했습니다. 원본 기록의 방향이 반대여서 각 구간 좌표를 역순으로 저장했습니다.
